## 2. 社区推广宣传素材合规要求

在准备论坛帖子、社交媒体推文、README 首屏宣传时，必须坚守以下铁律：

1. **宣传截图严格选用日常款**：
   - README 效果演示图统一采用**春/夏/秋/冬日常裙装或正装**（例如当前演示图 `docs/tryon-1.png` 为优雅蕾丝拼接鱼尾裙），严禁使用内衣、泳装或过分暴露款作为宣传吸引眼球。
2. **禁止虚假或低俗吸睛**：
   - 严禁在标题或推广文案中使用「擦边、福利、成人、色情」等敏感词吸引流量。
   - 宣传文案应聚焦于：**「服装设计参考图库」**、**「AI 人脸保留虚拟试穿搭配」**、**「开源技术实现」**。
3. **保留分类的合法性说明**：
   - 数据集分类保留原始日文字段是为保障兼容性与完整服装设计参考属性。
   - 所有者与使用者需遵守许可协议，不得将素材用于未成年人或违背公序良俗的场景。
